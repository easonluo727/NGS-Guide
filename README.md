# NGS-Guide
A beginner-friendly guide to Next Generation Sequencing. This guide introduces the fundamental concepts, terminology, and workflows used in NGS. It is designed for readers with little or no bioinformatics experience. Technical concepts are introduced gradually using plain-language explanations, simulated examples, and practical workflows.

The repository contains the following Markdown documents:
* `00_RNAseq_environment_setup` explains how to set up an environment on macOS and Windows for an NGS pipeline.
* `01_ngs_overview` illustrates the skills and tools needed for NGS.
* `02_file_format` presents the characteristics and roles of common file formats used in NGS.
* `03_CLIPseq` demonstrates the overall pipeline for CLIP-seq, an RNA-sequencing method.
* `04_ATACseq` demonstrates the overall pipeline for ATAC-seq, a DNA-sequencing method.
